# Myspoti 简体中文体验版 · 2.0.2-beta.3-zh.1

> 🧪 **非官方社区汉化测试版**，不是原作者或 Spotify 官方发布。基于 [kota-zo/myspoti](https://github.com/kota-zo/myspoti) 的 2.0.2-beta.3 源码基线及本仓库 `i18n/zh-hans` 汉化分支。当前仍需 Android 实机进一步验收。

## 下载

在本 Release 页的 **Assets / 资源** 中下载 `myspoti-2.0.2-beta.3-zh.1-android-debug.apk`（**只有附件实际出现并能下载时才表示构建成功**）。Android 10+ 可尝试安装。此文件由 GitHub Actions 从公开汉化源码编译生成，发布前执行本地化静态检查、单元测试和 Android 编译。

### 请先阅读：这是一份体验版 APK

- APK 使用 Android **debug 签名**与开发版应用 ID `app.myspoti.dev`，显示为 “Myspoti dev”，不等同于原作者正式签名的 Myspoti / Myspoti Beta。
- 可能与正式应用并存；但不同构建使用的 debug 密钥可能不同，**未来新版本不一定能直接覆盖更新**。请在卸载或更新前备份应用内部离线数据；不要以正式稳定版对待。
- 仅能保证 GitHub Actions 显示的源码/编译检查结果；**尚未完成全部页面和机型的实机汉化与播放测试**。Spotify 的 API、账号和地区政策也可能影响实际播放。
- **请勿使用不明来源的二次打包 APK**。请检查本仓库的提交记录、[Actions 构建](https://github.com/HypnosysNyx/myspoti/actions)和此 Release 的附件。
- 如本页没有 APK 附件，此发布记录**不是可安装版本**，请按 [README 自行编译](https://github.com/HypnosysNyx/myspoti#自行编译中文版)。

## 汉化说明

- 新增中文 Android 字符串与复数资源（`values-zh`）。
- 保留原应用播放、下载、Spotify 登录和系统数据行为，不更改账号认证逻辑。
- 部分 Spotify 官方网页、第三方返回文本、歌名等不在汉化范围内。
- 汉化资源覆盖统计及回归检查见 [QA 报告](https://github.com/HypnosysNyx/myspoti/blob/i18n/zh-hans/docs/localization-QA-report-zh-CN.md)。

## 原版功能

广告处理、Spotify 登录、播放列表、无损 FLAC/AAC 下载、逐字/翻译歌词、视频、Spotify Connect、Android Auto、播客与有声读物等，功能描述和限制详见 [本仓库 README](https://github.com/HypnosysNyx/myspoti)。
